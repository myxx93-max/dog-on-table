# 项目与市场机会

## 1. 项目定义

「狗上桌」是餐饮食品安全公开信息查询与消费者行动工具的项目代号。它不替代监管部门，不做民间执法，也不对餐厅作未经证实的定性。它的价值在于降低公众查找、理解和追踪公开信息的成本。

项目面向中国大陆消费者，也适合独立开发者从单城、单数据源切入。任何人都可以 Fork 后独立开发、部署和经营，不存在必须加入的统一团队。

## 2. 真实问题

消费者面对的不是“完全没有信息”，而是信息分散、检索困难、主体难匹配、专业术语难懂、时间状态不清楚：

- 监管部门公开的抽检、处罚、检查和风险提示分布在不同网站或栏目。
- 同名门店、品牌、经营主体、分店地址容易混淆。
- 搜索结果可能混合旧闻、转载、投诉、营销内容和官方结论。
- 消费者不知道该向哪里反映问题，也不清楚需要准备什么材料。
- 信息更新后，旧页面仍可能被传播，造成误解。

## 3. 谁会使用

- 普通消费者：查询餐厅相关公开信息、理解记录的时间和性质。
- 家庭与聚餐组织者：在选择餐厅时查看可追溯的信息。
- 媒体与内容创作者：寻找可核验的公开资料和原始出处。
- 食品安全研究者、学生和公益组织：观察公开信息的发布与变化。
- 合规经营者：核对自身公开记录、提交纠错材料、改善食品安全管理。
- 独立开发者：将项目做成作品、城市产品或创业项目。

## 4. 市场切入：先小后大

不建议第一天就做全国全量平台。优先选择一个城市、一个明确的数据来源和一个高频查询场景。

### 可验证的切入口

1. 单城监管公示搜索：检索处罚、抽检和风险提示。
2. 商圈餐饮公开信息页：围绕消费者常去区域建立可检索目录。
3. 官方信息解释器：将监管文书中的关键字段解释为普通消费者能理解的语言，并保留原文。
4. 举报办事导航：根据地区展示官方渠道和材料准备提示。
5. 内容驱动查询：围绕公开、已核验的监管信息制作解释型内容，导向原始出处和查询页面。

## 5. 流量前景：机会与限制

潜在流量入口：
- 搜索引擎：餐厅名称、食品安全抽检、行政处罚、食品安全风险提示等长尾查询。
- 短视频与图文：监管信息解读、食品安全常识、消费者维权流程。
- 本地生活社群：社区、学校、家庭、商圈和城市话题。
- 分享传播：具体门店信息页、官方公告解读页、办事指南。
- 媒体引用：有来源、有时间、有纠错机制的结构化信息。

限制：
- 用户查询需求可能低频，不能仅凭社会关注度推断高留存。
- 公开数据的覆盖、更新频率和结构化程度因地区而异。
- 监管数据的法律含义需要准确解释，错误归因会产生名誉和法律风险。
- SEO 和短视频流量不稳定，平台规则和内容审核会变化。
- 全国扩张需要持续的数据维护、申诉处理和法律合规投入。

验证指标应是实际查询量、有效搜索成功率、回访率、纠错处理时长、来源覆盖率和数据新鲜度，而不是单纯下载量或播放量。

## 6. 竞争与差异化

替代方案包括监管部门官网、国家及地方政务服务入口、地图/点评平台、新闻媒体和消费者投诉平台。项目不应宣称替代它们。

可形成的差异：
- 跨来源统一检索，但逐条显示来源。
- 主体与地址消歧，避免把同名门店混为一谈。
- 事件时间线和状态更新。
- 将“官方结论、媒体报道、用户反馈、模型推断”分开呈现。
- 直接引导用户进入正确的官方办事渠道。

## 7. 验证路线

第一阶段只回答三个问题：
1. 是否能稳定合法地取得一类公开数据？
2. 是否能准确匹配到正确餐饮主体？
3. 是否有真实消费者愿意用它完成一次查询？

未得到这三个问题的真实证据前，不应先投入全国采集、复杂评分或大规模营销。
