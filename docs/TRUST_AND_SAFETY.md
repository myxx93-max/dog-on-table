# 法律、事实与隐私原则

本文是产品设计原则，不构成法律意见。独立运营者应根据实际业务、所在地和数据处理方式咨询专业人士并核验最新法规。

## 1. 不替代监管机关

本项目是信息查询和办事指引工具，不是执法机关、检测机构或官方认证平台。不得使用容易让公众误认为官方平台的名称、标识或措辞。

## 2. 信息分类

每条信息必须明确区分：
- 官方公开信息；
- 媒体报道；
- 用户提交的个人陈述；
- 模型抽取结果；
- 未核实线索；
- 已更正或已撤回的信息。

不得把投诉、举报、网络传言或模型推断写成监管部门已经认定的事实。

## 3. 名誉与纠错

- 对负面信息保留原始出处、发布日期和适用主体。
- 不将品牌、企业、门店、加盟店和同名主体混为一谈。
- 提供显著纠错和申诉入口。
- 收到可信更正材料后及时核查，必要时临时标注争议状态。
- 依法处理错误信息、个人信息和侵权通知。
- 更正应留下时间和变更记录，不静默篡改历史。

## 4. 举报功能

可提供官方投诉举报渠道导航、材料准备提示和用户文本整理。正式渠道可能包括全国统一的 12315 平台及各地市场监管部门公开入口，实际入口和受理范围需按地区核验。

严禁：
- 自动生成虚假投诉；
- 自动批量提交举报；
- 诱导用户夸大、捏造或拼接证据；
- 将举报数量当作门店违法结论；
- 向商家施压或以撤回曝光换取利益。

提交动作必须由用户自行审阅并确认。产品不得冒充监管机关，也不得承诺举报一定受理或立案。

## 5. 个人信息保护

- 只收集实现功能所必需的信息。
- 举报材料默认不公开。
- 对手机号、身份证号、面部、支付信息、家庭住址等敏感内容进行最小化处理和脱敏。
- 明确告知处理目的、保存期限、共享对象和删除方式。
- 设置权限控制、访问审计和安全事件响应流程。
- 不出售举报人信息，不公开未经同意的个人身份。

## 6. 数据来源与知识产权

- 优先官方开放数据和明确授权数据。
- 核验网站使用条款、版权声明、数据库权益和访问限制。
- 不绕过登录、验证码、付费墙或技术访问控制。
- 不抓取或传播非公开个人信息。
- 对媒体内容优先保存必要元数据和链接，避免未经授权全文转载。

## 7. 免责声明

页面应明确说明：信息仅用于帮助公众查找和理解公开资料；记录可能存在延迟、缺失或更正；最终监管认定以有权机关正式发布为准。用户应以原始公告和官方渠道为准。
