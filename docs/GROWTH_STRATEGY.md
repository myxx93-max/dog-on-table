# 增长与内容传播

## 1. 增长定位

项目不是靠制造恐慌增长，而是靠“查得到、看得懂、能追溯、能纠错”建立信任。内容传播应把用户带回原始来源和查询工具，而不是鼓励网暴。

## 2. 搜索引擎

可做的页面：
- 城市 + 餐饮食品安全公开信息；
- 具体监管公告的解释页；
- 食品安全抽检常见问题；
- 消费者投诉举报流程指南；
- 门店公开记录时间线（仅在主体匹配可靠时）。

SEO 页面必须显示来源、发布时间、数据更新时间和纠错入口。不要批量生成无来源的门店负面页。

## 3. 抖音图文与短视频栏目

建议栏目：
- 「一分钟看懂一条官方公告」
- 「消费者如何正确保存证据」
- 「市场监管投诉举报渠道怎么找」
- 「食品安全术语翻译成人话」
- 「某城市公开数据月度观察」
- 「这个查询页面怎么使用」

内容结构：
1. 问题是什么；
2. 原始信息来自哪里；
3. 时间和主体是什么；
4. 能确认什么、不能确认什么；
5. 消费者可以通过什么正式渠道了解或反映；
6. 更正与补充如何提交。

避免用“全网曝光”“黑店”“必吃/绝对安全”等绝对化措辞。

## 4. 内容合集设计

可以按主题建立合集：
- 餐饮食品安全公开信息入门；
- 看懂抽检与行政处罚；
- 城市食品安全信息观察；
- 消费者依法投诉举报指南；
- 开源开发过程与数据工程实践。

每条内容尽量有原始出处或官方渠道指引。平台规则变化时重新核验，不依赖过时的流量技巧。

## 5. 本地传播

- 社区和高校食品安全科普；
- 与食品科学、法律、公共卫生、设计专业人士开展公开交流；
- 城市开发者活动和开源分享；
- 与媒体或公益组织合作，明确资料来源和责任边界。

## 6. 衡量增长

核心指标：
- 从内容进入查询页面的有效访问；
- 用户是否完成一次查询；
- 搜索成功率；
- 原始来源点击率；
- 回访与收藏；
- 内容纠错率；
- 举报导航点击（不等于正式投诉量）。

不要把播放量、争议评论数或投诉数量作为唯一成功指标。
