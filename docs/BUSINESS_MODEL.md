# 商业模式与边界

## 1. 基本原则

商业化可以支持产品持续运营，但收入不能改变事实呈现、查询排序、风险状态或举报通道。消费者信任是产品资产，不能出售。

## 2. 可探索的收入来源

### A. 明确标识的广告
- 本地生活、餐饮用品、食品安全培训、检测服务等合规广告。
- 广告必须清晰标识，与自然搜索结果、官方信息和风险记录视觉区分。
- 不得根据广告主付费情况改变门店信息、风险排序或搜索结果。

### B. 企业合规工具
- 食品安全自查清单、培训记录、整改任务、巡检记录。
- 面向经营者的合规知识库和提醒工具。
- 企业端工具与公众查询数据隔离，不能购买公众侧负面信息的删除或降权。

### C. 合规数据整理服务
- 为研究机构、媒体或企业提供公开资料的结构化整理、来源索引和更新提醒。
- 只处理合法公开或获得授权的数据，遵守来源网站条款、个人信息保护和数据安全要求。
- 明确数据覆盖范围、更新时间和缺失情况，不将数据包装成官方背书。

### D. 赞助与公益合作
- 透明披露赞助方、资金用途和合作范围。
- 赞助方不得干预事实判断、举报入口和纠错结果。

### E. 技术服务
- 为地方组织或机构提供搜索、数据归档、信息无障碍展示和公开数据可视化等定制服务。
- 合同明确数据来源、责任边界和交付范围。

## 3. 明确禁止的商业模式

**不得收取所谓“保护费”。** 不得以发布、保留、删除、隐藏或放大负面信息相威胁，向餐饮商家索取钱财或利益。

不得：
- 以删除处罚、投诉、抽检等真实公开信息为条件收费。
- 以不曝光、不推送、不举报作为付费条件。
- 出售虚假“安全认证”“官方评级”或付费洗白。
- 让商家付费购买更低风险等级或更高搜索排名。
- 以消费者投诉为筹码进行谈判、勒索或骚扰。
- 组织恶意刷投诉、批量举报或虚构证据。

这类行为会破坏项目的公共价值，并带来严重法律风险。

## 4. 商业产品与公共信息隔离

建议采用明确隔离：
- 公共事实层：来源、原文、发布时间、主体、事件状态。
- 用户反馈层：用户陈述、提交时间、审核状态。
- 商业服务层：广告、企业工具、赞助和技术服务。

商业层不能写回公共事实层。广告系统不应向事实数据库提供“付费优先”字段。

## 5. 单位经济与成本验证

不要在没有真实运营数据时编造收入预测。每个独立开发者应自行记录：
- 每月有效查询用户、回访用户和查询成功率。
- 广告展示、点击、投诉率和广告收入。
- 数据采集、核验、存储、带宽、内容审核和法律咨询成本。
- 企业付费转化、续费率和服务交付成本。
- 纠错、申诉、下架和用户支持工时。

广告收入不足以覆盖数据维护时，应缩小地域和数据范围，而不是降低核验标准。

## 6. 推荐商业化顺序

1. 免费查询和来源透明，验证真实需求。
2. 透明广告或公益赞助，验证是否有可持续流量。
3. 企业自查与培训工具，验证是否有独立付费需求。
4. 合规数据服务和技术服务，验证机构客户需求。

商业化必须建立在可信数据和真实使用之上。
