## 建议阅读顺序

- 想判断值不值得做：先读项目与市场机会。
- 想看怎么赚钱：读商业模式与边界。
- 想直接动手：读产品规划、技术架构和独立开发路线。
- 想公开 MFI 思路：读 MFI 方法概要。
- 想做内容传播：读增长策略。
- 想了解项目的社交与个人价值：读跨专业协作与个人收益。

## 当前仓库状态

当前提交的是项目构想、产品规划和技术设计文档，**尚未包含可直接运行的完整 Web、小程序或 App 源码，也没有真实餐饮监管数据集**。后续实现者应从合法公开数据源和小范围真实用户验证开始。
